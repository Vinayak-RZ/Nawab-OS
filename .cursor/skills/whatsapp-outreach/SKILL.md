# WhatsApp outreach

## Format
- **Max 280 characters** (hard cap 300).
- First line: who you are + why this number (mutual context if any).
- One specific hook from research.
- One soft CTA (reply yes / share time / intro to decision-maker).

## Rules
- Human tone — like a text to a colleague, not marketing blast.
- No links in first message unless user provided one.
- No ALL CAPS, no emoji spam, no "Dear Sir/Madam".
- Approval required before every send — draft only.

## Anti-patterns
- Bulk greeting templates
- "Limited time offer"
- Multiple questions in one bubble
- Pretending prior relationship without proof
